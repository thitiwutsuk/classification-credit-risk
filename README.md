# Credit Risk Analysis (วิเคราะห์ความเสี่ยงด้านเครดิตของลูกค้าธนาคาร)

โปรเจกต์นี้วิเคราะห์ข้อมูลลูกค้าธนาคาร เพื่อหาคำตอบว่า **อะไรทำให้ลูกค้าถูกมองว่า "เสี่ยง" (Credit Risky)** และ **ลูกค้าที่ "น่าเชื่อถือ" (Credit Worthy) มีพฤติกรรมแบบไหน**

## โครงสร้างโปรเจกต์

```
.
├── analysis.py                     # script วิเคราะห์ข้อมูลทั้งหมด
├── requirements.txt                # รายชื่อไลบรารีที่ต้องติดตั้ง
├── data/
│   ├── customer_data.csv           # ข้อมูลลูกค้า + label
│   ├── payment_data.csv            # ประวัติการชำระเงิน
│   └── dataset_description.md      # คำอธิบายความหมายของแต่ละคอลัมน์
└── output/                         # กราฟและตารางสรุปที่ script สร้างให้ (รันแล้วถึงจะมี)
```

## ข้อมูลที่ใช้

มีไฟล์ข้อมูล 2 ไฟล์ในโฟลเดอร์ `data/` (คำอธิบายคอลัมน์แบบละเอียดอยู่ที่ [`data/dataset_description.md`](data/dataset_description.md)):

| ไฟล์ | อธิบาย |
|---|---|
| `data/customer_data.csv` | ข้อมูลลูกค้า 1,125 คน มีคอลัมน์ `label` บอกว่าลูกค้าเสี่ยงหรือไม่ (`1` = เสี่ยงสูง, `0` = น่าเชื่อถือ) และมีข้อมูล demographic อื่นๆ (`fea_1` - `fea_11`) ที่ถูกเข้ารหัสเป็นตัวเลขไว้แล้ว |
| `data/payment_data.csv` | ประวัติการชำระเงินของลูกค้า 8,250 แถว (คนหนึ่งอาจมีหลายแถว เพราะมีหลายผลิตภัณฑ์สินเชื่อ) เช่น จำนวนครั้งที่ค้างชำระ, จำนวนครั้งที่จ่ายปกติ, วงเงิน, ยอดคงเหลือ |

## Script ทำอะไรบ้าง

ไฟล์ [`analysis.py`](analysis.py) ทำงานตามลำดับขั้นตอนแบบ data science ทั่วไป:

1. **โหลดและรวมข้อมูล** — สรุปประวัติการจ่ายเงินของลูกค้าแต่ละคน (จากหลายแถว) ให้เหลือคนละ 1 แถว แล้วนำไปรวมกับข้อมูล demographic
2. **ทำความสะอาดข้อมูล** — เติมค่าที่หายไปอย่างเหมาะสม (เช่น ไม่มีประวัติจ่ายเงิน = เติม 0, ไม่รู้วงเงิน = เติมค่ากลาง)
3. **สำรวจข้อมูล (EDA)** — เปรียบเทียบพฤติกรรมของกลุ่มเสี่ยงกับกลุ่มน่าเชื่อถือ ทั้งในรูปตัวเลขและกราฟ
4. **สร้างโมเดลทำนาย** — ใช้ Logistic Regression และ Random Forest ช่วยจัดอันดับว่าปัจจัยไหนสำคัญที่สุดจริงๆ (ไม่ใช่แค่ดูด้วยตาเปล่า)
5. **สรุปผลเป็นภาษาคน** — แปลงตัวเลขและผลโมเดลให้เป็นคำตอบของ Q1 และ Q2 ที่อ่านเข้าใจง่าย

## ผลลัพธ์ (Conclusion)

### Q1: อะไรทำให้ลูกค้าเป็น Credit Risky?

ปัจจัยหลักที่ทำให้ลูกค้าถูกมองว่าเสี่ยง คือ **พฤติกรรมการใช้เงินและการชำระเงิน** ไม่ใช่ข้อมูล demographic:

- **มียอดหนี้/ยอดคงเหลือสูง** — ลูกค้าเสี่ยงมี `highest_balance` (ยอดคงเหลือสูงสุดในประวัติ) เฉลี่ยสูงกว่ากลุ่มน่าเชื่อถือกว่า 2 เท่า
- **ค้างชำระบ่อยกว่า** — สัดส่วนการค้างจ่าย (`overdue_ratio`) และจำนวนวันค้างจ่ายรวม สูงกว่ากลุ่มน่าเชื่อถืออย่างชัดเจน
- **จ่ายเงินตรงเวลาน้อยกว่า** — จำนวนครั้งที่จ่ายปกติ (`pay_normal_sum`) ต่ำกว่ากลุ่มน่าเชื่อถือประมาณ 30%
- ข้อมูล demographic ที่เข้ารหัสไว้ (`fea_1, fea_3, fea_5, fea_6, fea_7, fea_9`) มีความแตกต่างระหว่าง 2 กลุ่มค่อนข้าง **น้อยมาก** เมื่อเทียบกับปัจจัยด้านพฤติกรรม

**สรุปสั้นๆ**: คนที่มีหนี้สูง + ค้างจ่ายบ่อย + จ่ายตรงเวลาน้อย คือกลุ่มเสี่ยงหลัก

### Q2: ลูกค้า Credit Worthy มีพฤติกรรมอย่างไร?

ลูกค้าน่าเชื่อถือมีลักษณะตรงข้ามกับกลุ่มเสี่ยง:

- **คุมยอดหนี้/ยอดคงเหลือให้อยู่ในระดับต่ำ** เมื่อเทียบกับวงเงินที่มี
- **แทบไม่ค้างชำระ** — สัดส่วนการค้างจ่ายเฉลี่ยอยู่ที่ประมาณ 3% เท่านั้น
- **จ่ายเงินตรงเวลาอย่างสม่ำเสมอ** — มีจำนวนครั้งจ่ายปกติเฉลี่ยสูงกว่ากลุ่มเสี่ยงชัดเจน

**สรุปสั้นๆ**: ความสม่ำเสมอในการจ่ายเงินตรงเวลาและการควบคุมยอดหนี้ คือสัญญาณของลูกค้าน่าเชื่อถือ

### ข้อควรระวัง

- โมเดลที่สร้างมี ROC-AUC ประมาณ 0.68 (จาก 1.0 คือแม่นสมบูรณ์ 0.5 คือสุ่มเดา) แปลว่าพอแยกแยะได้ในระดับหนึ่ง แต่ยังไม่แม่นยำมาก เนื่องจากข้อมูลมีขนาดเล็ก (1,125 คน) และไม่สมดุล (มีลูกค้าเสี่ยงเพียง 20%)
- ผลลัพธ์นี้บอกความ "สัมพันธ์" (correlation) ไม่ใช่ "สาเหตุ" (causation) — เช่น ยอดหนี้สูงอาจเป็นทั้งสาเหตุและผลลัพธ์ของความเสี่ยงพร้อมกันได้ ควรใช้เป็นแนวทางประกอบการตัดสินใจ ไม่ใช่ข้อสรุปเด็ดขาด
